Project Overview

TDE-LIO is a tightly-coupled LiDAR-Inertial Odometry framework specifically engineered for quadruped robots. While conventional LIO systems assume smooth trajectories and clean inertial data, legged locomotion introduces severe vulnerabilities: repetitive foot-ground impacts, intense physical vibrations, and highly fluctuating motion profiles.

These inherent disturbances corrupt IMU measurements, leading to degraded preintegration and inaccurate LiDAR motion deskewing. TDE-LIO effectively mitigates these issues by proposing a novel external disturbance compensation mechanism, enabling highly robust and drift-free state estimation under dynamic locomotion.

Core Technical Contributions

📈
External Disturbance Modeling via Time Delay Estimation

Analytically quantifies and models high-frequency, unknown physical disturbances acting on the IMU during dynamic quadruped locomotion by leveraging a mathematically rigorous TDE framework.

📐
Robust IMU Preintegration based on ESKF

Jointly updates the IMU orientation and the estimated disturbance uncertainty model within an Error-State Kalman Filter, effectively neutralizing vibration-induced drift prior to inertial integration.

📡
Enhanced LiDAR Deskewing & Motion Compensation

Exploits the refined, high-fidelity inertial pose estimations to accurately deskew sequential LiDAR sweeps, inherently preserving sharp geometric features and preventing environmental map blurring.

System Architecture

The proposed pipeline operates entirely on exteroceptive and proprioceptive sensing (a 3D LiDAR and an onboard IMU), eliminating the dependency on complex leg kinematics or external foot-contact sensors. Experimental Validation

We comprehensively benchmarked the framework utilizing the Unitree Go2 quadruped platform equipped with a high-rate 3D LiDAR.

The system was rigorously evaluated across a spectrum of demanding deployment scenarios, including:

  • Structured indoor corridors & wide outdoor environments.
  • High-speed dynamic locomotion regimes.
  • Severe, mechanically induced vibration configurations.

Compared to standard LIO baselines lacking external disturbance compensation, TDE-LIO demonstrates noticeably smoother trajectory tracking and produces highly consistent, geometrically accurate point cloud maps—entirely suppressing the "blurring" or "ghosting" effects typically caused by foot-impact vibrations.

Getting Started

The system is built and tested natively on Ubuntu 20.04 running ROS Noetic.

1. Install Dependencies

sudo add-apt-repository ppa:borglab/gtsam-release-4.0
sudo apt update
sudo apt install libgtsam-dev libgtsam-unstable-dev

2. Build the Workspace

cd ~/catkin_ws/src
git clone https://github.com/HoangHungIRL/TDE-LIO.git
cd ..
catkin_make

3. Run the Estimator

source devel/setup.bash
roslaunch tde_lio run.launch

# In a new terminal tab:
rosbag play your_dataset.bag
